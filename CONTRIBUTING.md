# Contributing Guidelines

Thank you for your interest in contributing to Google Multi-Account Shield!

## How to Contribute
1. **Fork the Repository**: Create your own fork and branch off from `main`.
2. **Setup Locally**: Follow the installation instructions in `README.md`.
3. **Make Changes**: Implement your feature or bug fix.
4. **Test Thoroughly**: Run `npm test` and validate the extension in Chrome. Ensure no new errors are introduced.
5. **Submit a PR**: Provide a detailed description of your changes, the problem they solve, and steps to verify them.

## Code Style
- Use standard ES2024 JavaScript.
- Avoid external dependencies where possible. Keep it lightweight.
- Ensure all automated checks (`ci.yml`) pass.
